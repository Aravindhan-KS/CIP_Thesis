\chapter{SYSTEM DESIGN}

\section{Design Overview}

The proposed system design aims at developing a dependable hybrid Quantum Support Vector Machine (QSVM)-based system for detecting anomalies and assessing risks in electric vehicle (EV) battery charging systems. The architecture is inspired by existing quantum machine learning-based battery anomaly detection solutions, particularly those based on unsupervised clustering algorithms such as K-means.

Although clustering-based methods can identify coarse deviations in battery behaviour, they often fail to detect subtle early-stage anomalies and lack clear decision margins. To overcome these limitations, the proposed system replaces clustering with a margin-based hybrid QSVM classifier combined with a risk-oriented decision layer.

The system follows a modular pipeline architecture in which each module performs a specific transformation and passes its output to the next stage. This design improves interpretability, scalability, and ease of integration with existing battery management systems.

\section{System Overview}

The EV battery time-stamped sensor data is processed through the following modules:

\begin{itemize}
\item Data Acquisition
\item Data Preprocessing
\item Classical Feature Engineering
\item Quantum-Inspired Feature Mapping
\item Hybrid QSVM Classification
\item Risk Assessment and Output Monitoring
\end{itemize}

Data preparation and baseline feature extraction are performed using classical machine learning techniques. Quantum-inspired transformations are then used to enhance the feature representation before classification using a QSVM model.

\section{Data Acquisition Module}

The data acquisition module gathers time-stamped sensor data from EV battery packs during charging cycles. Each record contains synchronized measurements of:

\begin{itemize}
\item Voltage
\item Current
\item Temperature
\item State of Charge (SOC)
\end{itemize}

These parameters collectively form a multivariate time-series representation of battery behaviour. Since battery anomalies often result from interactions between multiple parameters rather than single threshold violations, collecting multiple sensor signals provides a more comprehensive monitoring framework.

\begin{algorithm}
\caption{Battery Data Loading Module}
\begin{algorithmic}
\STATE \textbf{Input:} NASA battery .mat files
\STATE \textbf{Output:} Structured dataset $D$

\FOR{each battery file $B_i$}
    \STATE Load $B_i$ using MATLAB reader
    \STATE Extract cycle structure
    \STATE Separate discharge, charge, impedance cycles
    \STATE Store structured data in $D$
\ENDFOR

\STATE \textbf{return} $D$
\end{algorithmic}
\end{algorithm}

\section{Data Preprocessing Module}

Raw sensor data may contain noise, outliers, and variations in measurement scales. Therefore, preprocessing is necessary before feature extraction.

The preprocessing module performs:

\begin{itemize}
\item Noise filtering
\item Data normalization
\item Sliding window segmentation
\end{itemize}

Noise filtering reduces sensor disturbances, normalization ensures comparable feature ranges, and sliding window segmentation divides the time-series data into fixed-length windows that represent short-term charging behaviour.

\section{Classical Feature Engineering Module}

After preprocessing, statistical feature engineering is applied to extract meaningful descriptors from each window.

Typical features include:

\begin{itemize}
\item Mean
\item Variance
\item Rate of change
\item Stability indicators
\end{itemize}

These features form a structured classical feature vector representing the battery behaviour within a time window. This stage reduces the dimensionality of raw sensor data and provides interpretable inputs for further analysis.

\begin{algorithm}
\caption{Statistical and Electrochemical Feature Extraction}
\begin{algorithmic}
\STATE \textbf{Input:} Dataset $D$
\STATE \textbf{Output:} Feature matrix $F$

\FOR{each discharge cycle $c$ in $D$}
    \STATE Extract capacity
    \STATE Compute voltage statistics (mean, std, min, max, range)
    \STATE Compute current statistics (mean, std)
    \STATE Compute temperature statistics (mean, std, min, max)
    \STATE Extract impedance parameters (Re, Rct)
\ENDFOR

\STATE Compute Coulombic Efficiency:
\STATE $CE = \frac{Q_{discharge}}{Q_{charge}}$

\STATE Merge all features into $F$
\STATE \textbf{return} $F$
\end{algorithmic}
\end{algorithm}

\section{Quantum-Inspired Feature Mapping Module}

The quantum-inspired feature mapping module converts classical feature vectors into a higher-dimensional Hilbert space using quantum encoding techniques.

Initially, classical features are encoded using superposition-based representations, allowing multiple components to be represented simultaneously. Entanglement-inspired transformations are then applied to capture interactions between features.

These transformations increase the expressive capability of the feature space without requiring physical quantum hardware.

\section{Hybrid QSVM Classification Module}

The proposed system uses a hybrid QSVM classifier to detect anomalous charging behaviour.

Unlike clustering-based approaches, QSVM learns a margin-based decision boundary that separates normal and abnormal battery patterns in the transformed feature space.

The similarity between feature vectors is computed using a quantum kernel:

\[
K(x_i,x_j) = |\langle \psi(x_i)|\psi(x_j) \rangle|^2
\]

The QSVM combines quantum kernel feature mapping with classical SVM optimization.

\section{Risk Assessment and Output Generation}

The system includes a risk assessment module that interprets the QSVM output to classify charging behaviour into risk levels.

The anomaly score or decision margin produced by the QSVM is compared with predefined thresholds to categorize each sample as:

\begin{itemize}
\item High Risk
\item Low Risk
\end{itemize}

The final system outputs include:

\begin{itemize}
\item Risk level
\item Confidence score
\item Monitoring reports
\end{itemize}

\section{Design Summary}

The proposed system extends existing battery anomaly detection frameworks by incorporating quantum-inspired feature mapping within a classical machine learning pipeline. The use of a hybrid QSVM classifier enables better separation between normal and abnormal battery behaviour while maintaining interpretability and computational efficiency.
